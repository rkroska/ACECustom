BalanceBench.TestOnly: native gameplay, separate test harness

Keep the test runners, equipment setup, full three-DoT/streak rotation, shared camp automation, and per-caster damage logging. All charm mechanics, damage tuning, independent stacking, banking, Fracture, visuals and feedback come from native ACE.Server. This DLL contains none of the prototype gameplay classes.

Which mod to keep

  • Remove the old BalanceBench.dll prototype from the entire scanned Mods directory. Move its folder outside the mod tree, preserving a backup.
  • Install BalanceBench.TestOnly.dll using the supplied BalanceBench.TestOnly folder. It has a distinct assembly/mod identity. Do not rename the old DLL to this name.
  • The native legacy-prototype guard remains intact. It allows the separately built test-only mod and still rejects BalanceBench.dll.
  • The client-side mod can remain enabled. No live server switch, restart or configuration edit was performed to prepare this package.

Cutover for the local native test

  1. Stop the local server using the normal shutdown procedure. Preserve the existing server binaries, configuration and prototype folder.
  2. Build/deploy feature/nether-fracture-native from C:\Scripting\ACECustom using the normal build workflow. The earlier RC5 server package predates the master merge; do not use it as the current branch's native binary.
  3. Move C:\ACE\Mods\BalanceBench outside C:\ACE\Mods. Copy this package's BalanceBench.TestOnly folder into C:\ACE\Mods. The mod folder contains only BalanceBench.TestOnly.dll, ACE.Shared.dll, Meta.json and Settings.json.
  4. The build automatically copies the enabled, tested profile from source Config/nether-fracture.json. Do not overwrite it with another profile. If an existing ACE_NETHER_FRACTURE_CONFIG override is configured, verify that active file separately. Do not copy voidlab.json or voiddamage.json into the native schema.
  5. Start the native server and log in the five designated test characters. Keep all old runners stopped until the test-only audit passes.

Checks before a measured run

/bench testonly
/bench lab
/netherfracture show

The first command must pass the compiled-code purity audit. The second must identify BalanceBench.TestOnly v1, gameplayOverrides=False, realSustainRequired=True and native gameplay. Check the current configured ZC shows enabled=True and the frozen coefficients. An old voidlab-v3 probe is the prototype, not an acceptable native test.

What the harness can and cannot change

Explicit setup may equip/forge test gear, set a designated character's own augs or charm level, buff it through native mechanics, and spawn ordinary native camp templates. This is controlled test input, not a gameplay override. The harness cannot change global charm settings, native damage profiles or native banking. Setup/gear/charm/vital changes are blocked during a measured run.

Timed trials require sustain=1: native healing/mana casts and their time cost, with no automatic free refills. Explicit refills are allowed only outside a run, such as a seed's start. Synthetic shield multipliers, ratings and surges are excluded. Cleanup destroys tracked test spawns only.

Solo and shared real camps

Use the existing bench trial commands with spell=5394 dot2=5402 dot3=5338 spell2=5348 dot=10 combo=1 catalyst=1 sustain=1 castsec=2. Real camp selection still comes from the native DB templates. Native banks/cooldowns are never reset by the harness; they carry naturally across a camp chain.

For a shared camp, place Fourteen, Thirteen and Fifteen nearby in the same variation, idle. Arm the group before Fourteen's ordinary-health trial:

/bench fracturelab camp Balancefourteen,Balancethirteen,Balancefifteen
# Start Fourteen's standard bench trial through the runner.
# Afterwards, or to cancel the group:
/bench fracturelab stop

Group summaries record each caster, while kills are counted once for the shared camp. Telemetry separates Corrosion, Corruption, Curse, Nether Streak and nether-fracture, including direct/spread generations and landing/periodic ticks. native_fracture_hit records actual native damage. native_external_damage marks interference from an unapproved attacker and must invalidate that camp. Reject unclassified/missing effects instead of guessing a split.

# If the native build uses bin/x64/Release/net10.0, pass that actual directory instead.

Sources and the offline audit/negative fixture are under Tools/BalanceBench.TestOnly and Tools/BalanceBench.TestOnly.Audit on the native branch. The deliberately unsafe fixture is excluded from this installable package.

Validation performed

The compiled observer audit passed. Seventeen observer-patched methods bound successfully in an isolated process; native solo/group math and native banking produced identical results before and after patching. A negative fixture with a result multiplier, a native-skipping prefix, a native snapshot write and a prototype type was rejected. Native startup accepted the test-only mod identity and rejected the legacy prototype alongside it. No game world or live fight was started during these checks.

In-world native camp validation still follows the cutover. Do not treat the offline checks as native KPH results. BalanceBench.TestOnly is optional development instrumentation and is not required for production gameplay.
